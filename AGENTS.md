# Contribution instructions

- Preserve source URLs, publication dates, data periods, and retrieval dates in research outputs.
- Do not invent consensus estimates, price moves, catalysts, or chart interactions.
- Treat generated analysis as research, not personalized investment advice or trade execution.
- Run `scripts/validate.sh` before submitting a change.
- Never commit credentials, proprietary research reports, user portfolios, or generated client data.
